# Ponto W · Zoom no Diagrama

Deck da apresentação do Ponto W para a banca do Challenge GoodWe: 15 slides numa prancha técnica que dá zoom em cada etapa da jornada, com as telas reais do sistema.

## Como abrir

Abra o `index.html` no navegador (Chrome ou Edge). Precisa de internet para carregar a animação (GSAP) e as fontes; sem internet o deck abre e navega, só sem as animações e com fonte reserva.

## Teclas

| Tecla | Ação |
|---|---|
| → · ↓ · espaço · Enter · PgDn · clique na metade direita | próximo slide |
| ← · ↑ · PgUp · Backspace · clique na metade esquerda | slide anterior |
| Home · End | primeiro · último |
| F | tela cheia |
| T | tema claro / escuro |

Dá para abrir direto num slide pelo endereço: `index.html#s6`.

## Estrutura

- `index.html` — o deck inteiro (HTML, CSS e JS num arquivo só)
- `assets/` — capturas das telas do sistema usadas nas etapas
